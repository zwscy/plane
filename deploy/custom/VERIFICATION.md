# 功能与本地验证记录

## 本分支内容

- 项目设置独立管理自定义字段，支持 16 种类型；任务创建、详情、列表和表格接入字段值。
- 单值字段支持排序，数字按数值排序，空值置后；树形保持父子关系，各层同级排序。
- 保存只提交修改的字段键，保留并发修改；草稿转换、创建后排序、刷新失败和三层树异步渲染均有回归覆盖。
- 列表和表格提供自定义排序入口；看板、日历、时间轴及归档中的失效排序会恢复有效顺序。
- 移除 Community／版本徽标、GitHub 加星按钮，以及工作区账单导航和定价页面。旧定价地址显示现有 404 页面。
- 保留 `LICENSE.txt`、版权声明、原有状态管理及社区版功能逻辑。
- 移除帮助菜单及快捷命令中的文档、联系销售、论坛入口，移除新功能窗口中的重复文档／论坛链接，以及事件回调设置页的文档链接；保留事件回调功能。
- 补齐主应用导航、设置、任务、筛选、成员、活动记录和常用弹窗的中文文案。日期、日历及甘特图使用中文显示，保留数字日期偏好和 API 提交格式。

## 使用边界

- 预计工时为普通自定义数字，不自动汇总、计算人员容量或联动排期；多值字段不提供排序。
- 新增状态、周期、模块等引用字段独立保存，不改变任务原有业务关系。
- Web 和 API 为本仓库源码构建；辅助服务沿用固定的官方 CE `v1.4.3` 镜像，见同目录启动说明。
- 品牌、技术格式名称、示例地址和用户填写的名称／内容保留原值。辅助管理、公开分享等官方镜像不包含本次主应用文案修改。
- Chrome 初始化时观察到可恢复的 React hydration 日志，原因未进一步确认；上述页面操作已验证。
- dev2 部署等待用户完整测试确认，本次交付不包含 dev2 发布。
